## About The Project

Veel mensen, vooral vrouwen en jongeren, voelen zich ’s avonds onveilig wanneer zij alleen over straat lopen.  
**SafeWalk** is een Progressive Web App die dit gevoel van onveiligheid vermindert door:

- Real-time locatie delen
- Veilige routeplanning
- Paniekknoppen voor snelle hulp
- Automatische meldingen bij aankomst

De app is bedoeld om gebruikers **veilig en met vertrouwen** naar huis te laten reizen.

### Projectdoel

Een veiligheidsapp ontwikkelen waarmee gebruikers:
- Hun locatie kunnen delen met vrienden of familie
- Onderweg ondersteund worden
- Direct hulp kunnen inschakelen in noodsituaties

### Doelstellingen
- Ontwikkelen van een volledig functionele PWA binnen **6–7 sprints**
- Real-time locatie delen met geselecteerde contacten
- Paniekknop met notificaties
- Routeplanner met focus op veiligheid
- Automatische melding bij veilige aankomst
- Moderne, snelle en gebruiksvriendelijke interface

## Getting Started

### Prerequisites
- Node.js
- npm
- PHP & Composer
- Laravel
- Breeze

### Installation

1. Clone de repository
   ```sh
   git clone https://github.com/your_username/safewalk-app.git
2. Installeer frontend dependencies
    ```sh
    npm install
3. Backend dependencies
    ```sh
    composer install
4. Configureer .env
5. Start de applicatie
    ```sh
    npm run dev
    php artisan serve
    ```
